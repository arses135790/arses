# آرسس (Arses)

پنل سبک مدیریت پروکسی با VLESS و Trojan روی WebSocket، با داشبورد فارسی. بدون هیچ وابستگی npm (فقط Node 20 به بالا). کد کاملاً اورجینال است.

## امکانات
- ساخت نامحدود لینک، هر کدام با سهمیه‌ی حجم (GB)، تاریخ انقضا، فعال/غیرفعال و ریست مصرف
- هر لینک هم VLESS دارد هم Trojan، با QR و کپی با یک کلیک
- نمودار زنده‌ی سرعت، تعداد اتصال زنده، مصرف هر لینک
- با تمام شدن حجم یا انقضا، اتصال‌های باز همان لحظه قطع می‌شوند
- ورود با رمز (scrypt)، محدودیت تلاش ناموفق، کوکی امضاشده، CSP، جلوگیری از دسترسی کاربران به شبکه‌ی داخلی سرور (loopback / private / metadata)
- ذخیره‌ی داده در یک فایل JSON روی Volume

## دیپلوی روی Railway
1. این پوشه را در یک ریپوی GitHub (ترجیحاً private) بگذارید.
2. Railway → New Project → Deploy from GitHub repo.
3. در Variables اضافه کنید: `ADMIN_PASSWORD` (رمز دلخواه)، اختیاری `ADMIN_USER` (پیش‌فرض admin).
4. **Volume بسازید با Mount Path = `/data`** (بدون آن با هر دیپلوی لینک‌ها پاک می‌شوند).
5. Settings → Networking → Generate Domain، بعد `https://دامنه/login`.
6. اگر `ADMIN_PASSWORD` نگذاشته باشید، رمز پیش‌فرض `4320` است (بعد از ورود از «رمز عبور» عوضش کنید). برای ریست رمز، مقدار `ADMIN_PASSWORD` را عوض کنید.

لینک‌ها به‌طور خودکار با دامنه‌ی Railway ساخته می‌شوند (پورت 443 + TLS). اگر دامنه‌ی خودتان را وصل کردید، `PUBLIC_HOST=your.domain` بگذارید.

## متغیرها
| نام | پیش‌فرض | توضیح |
|---|---|---|
| `PORT` | 8000 | Railway خودش می‌گذارد |
| `ADMIN_USER` / `ADMIN_PASSWORD` | admin / تصادفی | حساب ادمین |
| `DATA_DIR` | /data | مسیر ذخیره‌سازی |
| `PUBLIC_HOST` | دامنه‌ی Railway | دامنه‌ی داخل لینک‌ها |
| `VLESS_PATH` / `TROJAN_PATH` | تصادفی (ذخیره می‌شود) | مسیر WebSocket |
| `CONFIG_ADDRESS` | خالی | آی‌پی امارات برای کانفیگ‌ها (از «تنظیمات کانفیگ» در پنل هم قابل تغییر است) |
| `UPSTREAM_PROXY` | خالی | پروکسی SOCKS5 خروجی (مثلاً سرور امارات) به شکل `socks5://user:pass@ip:port`؛ از «تنظیمات کانفیگ» هم قابل تغییر و تست است |
| `BLOCKED_PORTS` | 25 | پورت‌هایی که کاربران نمی‌توانند به آن وصل شوند |

## اجرای محلی و تست
```
ADMIN_PASSWORD=secret123 DATA_DIR=./data node server.js     # http://localhost:8000
npm test                                                    # 40 تست سرتاسری با ترافیک واقعی
```

## محدودیت‌ها (صادقانه)
- فقط TCP؛ UDP/QUIC و Mux پشتیبانی نمی‌شود. در کلاینت Mux را خاموش کنید.
- Shadowsocks و MTProto فعلاً ندارد.
- ادمین تک‌نفره است. لینک‌ها فقط با یک پروسس کار می‌کنند (replica را روی ۱ نگه دارید).
- Railway ممکن است استفاده از سرویس برای پروکسی را محدود کند؛ شرایط استفاده‌ی آن را بخوانید و مسئولیت استفاده با خود شماست.
